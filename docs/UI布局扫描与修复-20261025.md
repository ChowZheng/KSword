## 同类源码扫描

- 对 StyleParameterSection 的扫描匹配了 37 个源码文件中的 87 处调用。
  DDMA 调整后，仍有 21 处先登记样式、后创建布局的同类接入，分布在文件 IRP、网络请求、进程创建及内存证据等页面。
  共享 StylePrimaryGroup 现在在既有首帧主题回调中补齐布局：有标题顶部 22px，无标题顶部 4px，区内间距 8px。
  无标题 4px 与 FoldParameterSection 原正文留白一致；没有增加定时器或全局观察器。
- StyleParameterFields 原本会递归处理字段视图和编辑器自己的搜索/格式控件。
  现在以复合控件为边界，保留 StructuredFieldView、CodeEditorWidget、专业视口、投影与单独搜索控件的内部布局和样式拥有者。
- StructuredFieldView 保留原搜索、格式、复制、导出控件及其连接。
  工具行在宽屏单行显示，窄栏按实际动作尺寸换成多行；文档投影已转移控件后不再由原视图重排。
- ToolbarRowMetrics 复用既有机制支持 QLayout；FlowLayout 和字段工具网格通过不改间距的入口登记，
  在字号变化后继续按整组最大字体更新高度。原 QHBoxLayout 调用和间距参数保持兼容。
- 自动表头更新仅失效对应表头缓存，复用内容测量；不为 CPU / 内存汇总文字更新重复扫描单元格。
  表头测量同时采用 Qt 的 sectionSizeHint，覆盖模型尺寸、字体与图标角色及当前样式指标；
  参考 [Qt 6.9.3 QHeaderView 实现](https://github.com/qt/qtbase/blob/v6.9.3/src/widgets/itemviews/qheaderview.cpp#L513)。
- 窗口截图 helper 原本用非空占位图表示失败，调用方可能将它当作成功图片保存。
  现在失败返回空图，保存入口检查可捕获状态。显式保存当前主窗口的既有能力保留；自动预览避免主窗口递归画面。

## 保留的语义与边界

DDMA 两张表继续显式使用 None 操作条，避免与原业务动作重复；窗口消息表原 Compact 入口未改。
搜索、复制、导出继续使用同一份字段文档；表格模型、选择、排序、快照身份与专业编辑器内部滚动没有另建替代实现。
页根留白与卡片内边距承担不同职责，没有把“6px 页根 + 16px 卡片正文”误当作重复留白一并删除。

共享改动覆盖相应入口的行为，不等于所有页面已经逐页完成实机视觉验收。
未检查的旧页面不计为本轮 GUI 覆盖。
