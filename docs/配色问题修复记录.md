## 边界

多种背景跨越黑/白文字阈值时，可能不存在一种前景能同时达到4.5:1；实际状态/交替行应分别求色，不以降低文字验收值掩盖这个约束。HUD透出桌面、动画整体透明度与复杂明暗图片仍需实际合成画面验收。

本轮不执行真实命令、防火墙修改、监控启动、驱动操作或插件调试后端。静态、离屏与编译结果不等于所有生产GUI组合已验收；发布结果以实际Git提交、GPG签名及远端SHA读回为准。
