# 窗口控件检查

在窗口列表打开“窗口属性”，切到“控件检查”页即开始观察。默认检查所属顶层窗口；范围下拉框可改为原 HWND 子树。可分别查看 UIA 控件树、UIA 原始树及 Win32 子窗口树。

覆盖层平时点击穿透，悬停显示主题色高亮与属性卡片。右侧属性跟随悬停；鼠标返回详情窗后保留最后内容。点击树节点会显示该节点的属性并高亮对应位置，后续悬停其他控件不会改变树的选中项。

点击箭头或按 Ctrl+Shift+C 开启一次性拾取。下一次目标左键点击只用于选中控件，不执行目标动作；拾取后恢复正常操作。再次点击箭头、再次按快捷键或按 Esc 可取消；拾取期间 Esc 不传给目标，因此不会主动关闭目标菜单。快捷键仅在检查运行且前台是目标窗口、关联弹出窗口或当前控件检查页时处理。

“全部框选”“悬浮提示”可分别关闭。暂停后树仍可浏览；切换属性标签页继续检查，最小化详情窗或隐藏／最小化目标时暂停显示，恢复后继续。另一个详情窗启动检查时，原会话暂停。关闭详情窗或目标失效后结束检查。

仅展示系统接口实际暴露的信息。自绘、虚拟化及未实例化控件可能没有可读节点；UIA 未暴露子控件时可切换 Win32 视图。关联弹出窗口依据所有权及 GUI 线程活动关系确认，不会把同 PID 的所有窗口都纳入。首版不执行控件动作，不使用视觉识别、注入或驱动接口。

## 验证

运行 `tools/Invoke-ControlInspectionTests.cmd --dpi-matrix`。测试使用隐藏桌面验证 Win32 树、输入配对策略、页面生命周期和实际绘制；当前桌面上的不激活屏幕外工具窗口另行验证真实 UIA Provider 的逻辑子控件。测试不会切换输入桌面。低级钩子的真实物理输入及第三方程序兼容性仍需交互验收，输入策略测试不等同于该项验收。
