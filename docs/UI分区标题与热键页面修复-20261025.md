## 标题与留白的共同拥有者

- 新增 `UI/GroupBoxStyle.h`，统一无描边、卡片内部标题、600字重和正文间距。
  独立卡片标题左16px、上10px，正文左右及下方16px；标题顶部预留随实际字体高度增长。
- 参数区已由外卡拥有16px内距，嵌入分区从该内容边界起排；不重复套卡、增加侧边留白或绘原生图例/顶线。
- 组框自身layout边距归零，区内间距8px。删除 finish、折叠包装及窗口输入控制页重复写入的旧标题边距。
  无标题折叠正文仍为4px顶部预留。
- 普通卡片、参数、设置、应用基线、主窗口、弹窗及详情壳均引用共同配方，各自保留原表面/透明配色职责。
  不增加根QSS拥有者；二级窗口独占根皮肤的既有修复保留。
- 普通组框沿既有Polish/Show和ThemeBinding队列准备；字体变化只刷新这个已登记宿主。
  默认绑定只剔除窗口根上完整的两类已知共享主题块；残余业务QSS和不完整块仍阻止自动接管。
  没有新增全局扫描、定时诊断或事件日志。

## 用语与数据来源

简单清单使用“热键列表”“消息钩子列表”“设备与驱动状态”“剪贴板信息”和“刷新数据”。
网络页提供连接终止操作，原“网络只读审计”与实际功能不符，改为“网络连接分析”；导航及相关普通对话框为“网络分析”。
服务跨来源比对、安全分析、内核完整性等真实审计语义保留，内部类名/协议和业务权限未改。
中英语言包同步，仍被其它真实审计页引用的旧短词条保留。

进程属性截图中的多数条目来自PE Accelerator静态程序资源；原窗口“热键/钩子”仅请求系统注册热键，且默认等待手动刷新。
其PDB查询与备用查询共用同一驱动枚举后端，不能补出程序资源快捷键。
此次把现有唯一的“全部热键”实例移入“热键/钩子”的第一个“程序快捷键”内页，沿用其首显后台分批查询。
没有创建第二个全进程扫描器，也没有把静态资源伪装成已注册、正在使用或可删除的系统热键。
注册热键、消息钩子与摘要分别保留，驱动查询状态和失败信息不改为假成功。
PageNavigationBridge按真实页对象收集、按indexOf激活；Taskbar消费动态目录，没有该旧顶层页的固定索引依赖。

另见驱动桥未完整转递session/thread过滤参数的独立源码疑点；本页请求pid0，不构成已证明的本次空表原因。
本轮未修改驱动、协议或私有结构枚举，亦未实际验证本机R0查询是否成功。
