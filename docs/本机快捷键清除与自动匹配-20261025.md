# 本机快捷键清除与自动匹配

## 功能与导航

| 入口 | 页面类型和共享入口 | 行为 |
| --- | --- | --- |
| 窗口 → 热键/钩子 → 程序快捷键 | 主列表；ImmutableValueTable、Full操作条、AsyncOperation | 多选清除窗口激活热键和快捷方式文件的热键设置 |
| 窗口 → 热键/钩子 → 注册热键 | 现场清单；同一结果表和共享异步事务 | 按完整身份重新枚举后，清除当前版本支持的普通独立注册项 |
| 杂项 → 快捷键管理 | 生命周期/状态及导航代理；共享页根、动作行和主题 | 跳转现有管理实例；不创建第二份列表或扫描器 |
| 进程属性 → 进程热键 | 属性详情中的主列表；原详情框架 | 单项删除复用同一清除后端，编辑路径保留 |

菜单文字、PE Accelerator程序资源、回调、占位项和含子项的注册对象不伪装成可清除项。
选中这些来源时显示原因；混合选择按来源统计并跳过不支持的项。
快捷方式清除只验证文件配置，通知Shell更新不代表已验证Explorer的运行时注册已经消失。

规范目标随原始结果保留：列表排序/筛选后由模型角色中的稳定token和刷新代次取回目标，不能从显示文本或可视行号拼清除请求。
清除前确认一次选择；后台逐项执行，分别显示成功、跳过、失败或未确认的回执，结束后真实刷新一次。
窗口/文件/进程身份和原值在执行前再次检查；超时与读回失败不表示确定成功或确定未修改。
进程详情的模态确认返回后还复核存活、PID/创建时间、结果快照和选区身份。

杂项入口追加在原目录末尾，保留既有索引；目录预加载不触发导航或枚举。
MainWindow的惰性和常规构造路径共用一次信号接线，按真实页对象激活，失败保留状态和重试动作。
同类主列表对照了窗口总表、进程热键页；系统时间/虚拟位置参数页仅作页面分类对照，没有把结果列表误套参数表单。

- Full的NtUserUnregisterHotKey在RVA 0x1C8009/0x1C800B将EDX/ECX清零后调用EnterCrit；
  Base的EnterCrit在RVA 0x12F4F/0x12F51实际读取EDX/ECX。旧无参声明已改为两个ULONG参数并传0、0。
- Full热键表访问调用WIN32K.SYS的W32GetUserSessionState，而旧代码调用Base的UserGetSiloGlobals。
  实际WIN32K导出RVA 0x19020经函数调用后读取[rax]；Base导出RVA 0x15D7C0调用W32GetSiloSessionState后读取[rax+0x10]。
  驱动已按Full的实际导入解析正确导出，并检查模块范围、可执行节及非forwarder。
- 实际卸载调用链为NtUserUnregisterHotKey → _UnregisterHotKey（0x1C808C）→ HKRemoveMatchingHotkeys（0x1C8108）；
  查询类型为3；128桶位于UserSessionState+0x3290，next为0x30，缓存位为0x36A8。
  注册、插入与删除三条指令链对节点字段和表偏移交叉验证，不能只由单个字节签名推定布局。

## 驱动查询及版本边界

热键读取和变更经已有InCallerContext入口保留原调用者USER会话；R3后台线程先准备USER上下文。
指定PID失效、不具备所需执行级别、桶/链读取失败、自环及预算耗尽均保留真实错误/部分状态，不能返回成功空表。
桥接显式翻译两种协议的flags，按已确认会话及规范PID/TID筛选；未知归属不穿透进程过滤。

变更继续拒绝不完整快照、歧义身份、非普通项以及不匹配的调用者会话；没有扩大回调或子项的可变范围。
键盘协议升级为v3，结构保留v2布局；新客户端不会用旧v2回执发起清除，旧v2变更请求也不会进入新驱动写路径。
验收驱动清除需使用并重新加载本次生成的驱动，不能只替换主程序。

## 自动匹配工具

```powershell
python tools/pdb_offset_generator/match_win32k_hotkeys.py `
  --pair <win32kfull.sys> <win32kbase.sys> `
  --out <report.json> `
  --emit-driver-header KswordARKDriver/src/features/keyboard/keyboard_profiles.generated.h
```

`--pair`可重复传入已准备的配对文件；只读解析，不执行或修改输入二进制。
工具结合PE导出、异常表函数边界、Capstone解码、调用图和必经字段写入验证布局；缺失、歧义或不兼容一律unsupported。
报告记录SHA256、PE/RSDS和具体证据RVA/指令；只将通过的配对写入目录，重复配对拒绝重复授权。
驱动运行时再验证full/base双PE/RSDS、实际布局与删除函数首32字节，精确选择目录项。
当前生成目录只有本机这一组；其它版本需要取得样本并实际通过匹配及后续验证。
用户提供的版本站点已能通过只读HTTP访问并定位二进制下载接口，尚未批量下载跨版本样本。
