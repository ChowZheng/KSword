# 快捷键跨版本规则匹配：离线证据与运行时边界

## 当前实现

驱动在当前实际加载的 `win32kfull.sys`、`win32kbase.sys` 映像上运行同一套有界纯 C 规则。规则从导出、实际导入、PE 函数边界和解码指令出发，交叉证明注册节点的字段、会话热键表、桶循环、安装线程与窗口身份比较、缓存清零，以及一参链槽 helper 的摘链和释放路径。`ScanRva` 是已验证身份筛选的扫描函数；`RemoveRva` 是另行证明的单节点链槽 helper。两个入口不能互换。

规则按当前映像推导偏移和入口，不查询 Windows build、SHA、PDB GUID 或样本 RVA 白名单。成功结果连同已分析函数、PE 元数据、导入表与 IAT 的代码指纹缓存；变更前复核缓存代次、实际会话 getter 和代码。缺失、歧义、预算不足或身份变化均拒绝发布可调用结果。未来映像可以通过**同一语义规则**取得结果，但未知构型是否满足规则必须逐个验证，不能由下表外推。

过去的 `tools/pdb_offset_generator/match_win32k_hotkeys.py` 与 `keyboard_profiles.generated.h` 是逐配对生成目录的历史方案。当前运行时授权由 `KswordARKDriver/src/features/keyboard/keyboard_rule_match.c`、`keyboard_rule_runtime.c` 及其 `proof`/`flow`/`slot`/`loop` 模块完成；生成目录不再用于选择可变热键布局。

## 跨形态的同源证明

- 22621 三组从 `win32kbase.sys!gptiCurrent` 导入数据取得安装线程，采用索引 `0→N` 的会话表循环；26100 三组从当前线程 getter 的实际调用链取得安装线程。26100.5074 的注册构造器多一层透明包装，规则核对该包装的全部返回路径后规范为相同底层来源。
- 桶数 `N` 来自插入时的哈希掩码。循环模块接受计数 `N→0`、计数 `0→N` 加八字节桶指针、以及索引 `0→N` 且每轮以同一 getter 读取节点和取得链槽三种语义。初始化、步进和回边必须由 CFG 必经关系证明；输入寄存器、栈指针伪步进和不同会话表来源不能借用证据。
- 26100.1 与 26100.5074 把主扫描内联进两参包装器；另外四组使用四参扫描函数。身份比较必须同时涵盖普通窗口相等，以及节点和输入均为特殊值 `1` 的分支，不能把汇合后的条件跳转单独算作窗口守卫。
- 一参 helper 的 `RCX` 是保存节点指针的**链槽地址**。普通成功分支将槽改为当前节点的 next，随后沿已验证释放路径释放同一节点；带子项的路径可能改变占位状态并返回零。因此布尔零不证明没有副作用，运行时仍需完整快照、普通项门禁、身份重查和操作后读回。

六组的 `CacheOffset - TableOffset` 恰好都为 `0x418`，仅是交叉观察；当前规则还独立验证注册后的缓存清零、卸载侧同 getter 的 `cmp 0` 与零写入，不使用该差值单独推定偏移。

## 验证与尚未验证

离线探针 `tools/hotkey_rule_probe.c` 把 PE 字节映射为**只读输入数据**，直接调用生产 C 规则。最终规则在上述六组上全部匹配；`python tools/test_hotkey_runtime_rules.py` 及兼容入口对同一套用例为 22/22 通过。用例包括错误桶数、表偏移、会话导入槽、寄存器宽度丢失、CFG 绕过和包装器副作用的拒绝，以及注册、桶循环、单槽释放和整体匹配。规则与探针源码组合 SHA256 为 `2103a32e11b6d520b2ae12ad63df858afcadbb599f5e3915d6fdfbce80c1537d`，完整样本身份、逐项结果、证据指令和宿主哈希见[正式验证报告](hotkey_matching/runtime-rule-validation-20261025.json)。该次测试与构建后仅补充中文注释及修正字段注释；新增规则模块已逐文件核对去注释token一致，算法和声明未改变。到此未因注释变化重复产品构建。前五组下载及 PE/RSDS 核验原始清单在 `.codex-build-logs/hotkey-cross-version-20261025/manifest.json`。

这些结果验证静态文件字节和离线纯 C 规则。实际加载、USER 会话运行、GUI 与真实快捷键清除由用户实机验收。运行时还必须完成真实导入目标绑定、代码/元数据/IAT 稳定性、调用者会话、完整节点快照和全桶唯一性检查；不能把六组样本 RVA 当作版本支持目录。
