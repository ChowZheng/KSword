# Corresponding source

This package is built from the local KSword working tree. Local changes may
not yet be published in the upstream repository; do not treat an older
upstream commit as the corresponding source for these binaries.

`KSword-cheat-engine-source.zip` contains these current KSword sources, the
shared protocols and debugger/HVM driver sources, with per-file SHA256 hashes.
The complete unmodified Cheat Engine source remains available from its project
URL below; it is separate from KSword's corresponding source archive.

Repository:

https://github.com/KSwordDEV/KSword

Relevant paths:

- `CheatEngineExecutablePlugin/`
- `CheatEnginePlugin/`
- `DebuggerBackend/`
- `Ksword5.1/Ksword5.1/ArkDriverClient/`
- `shared/driver/KswordArkDebuggerIoctl.h`
- `shared/driver/KswordArkHvmDebugIoctl.h`
- `KswordARKDriver/src/features/debugger/`
- `KswordARKDriver/src/features/hvm/`

The bundled Cheat Engine 7.6 user-mode distribution remains the work of the
Cheat Engine project. Its upstream source is available at:

https://github.com/cheat-engine/cheat-engine
